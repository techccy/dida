# dida — 产品概览（UI 重设计锚定）

> 本文件不重定义产品——产品事实以 `DESIGN.md` 为唯一来源。此处只记录 UI 重设计的范围锚点。

## 一句话定位

网页版 **1对1 临时端到端加密对话平台**：临时对话（C 码）+ 内容提取（E 码），核心卖点 **不留痕迹 + 诚实的安全边界声明**。

## 四条路由与重设计后的形态

| 路由 | 功能事实（DESIGN.md §3，不变） | UI 重设计形态 |
|---|---|---|
| `/` Entry | 分格码输入 + 粘贴 + 加入；无 logo、无介绍、不暴露能力 | 微氛围背景，输入居中为唯一视觉主角 |
| `/admin` | 登录 → 会话（创建/列表/提前结束/内嵌聊天）+ 提取包（创建/列表/提前销毁） | 登录独立屏；登录后分区导航（会话/提取包），内容区重排 |
| `/c` Chat | 消息列表 + 输入 + 状态 + 倒计时；信息包气泡；水印门控 | 全高 messenger 式：顶栏（状态+倒计时）/消息流/吸底输入 |
| `/extract` | 凭码兑换解密；packet=截断+复制 / message=只读；sessionStorage 回看 | 单卡片聚焦式，结果区按呈现样式重排 |

## 不可动摇的约束（实现时不得回退）

1. 主页无 logo、无功能介绍（DESIGN.md §3【决策】）。
2. 分格输入交互模型：单一隐藏 input + 视觉切格、顺序填充、粘贴归一化整体替换、填满不自动提交、非法字符提交时统一校验。
3. 信息包气泡：截断预览（前 24 字符）+ 独立复制按钮，两端对称渲染。
4. 水印：canvas 渲染、渲染门控、devtools 模糊等逻辑全部保留，视觉只调主题适配参数。
5. 提取失败统一模糊文案「提取码无效或已失效」。
6. 对外文案与 DESIGN.md §13 隐私声明一致，不夸大。
